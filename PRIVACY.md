# Privacy

Skribi is local-first software.

- No account or sign-in.
- No analytics, telemetry, advertising, or tracking.
- No background network service.
- No document upload or cloud sync.
- No collection by Implose Cybernetics through the application.

Skribi reads and writes only the folders and files you choose through the operating-system file picker or launch argument. It stores the last opened library path in the operating system’s normal application-data location. Retex-compatible edits may create `.retex/history.jsonl` and lock files inside the selected folder.

Opening an external Markdown link may pass the URL to your operating system and default browser. Any resulting network request is governed by the destination’s privacy policy, not Skribi.

Because Skribi does not operate a service, there is no remote account or server-side personal data to delete. Delete the application’s local settings through the operating system and remove any files you no longer want to retain.
